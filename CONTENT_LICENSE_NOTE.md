# Content License Note

Lernen uses two licenses to cover different categories of files in this repository:

## AGPLv3 (LICENSE file)

Applies to all source code in `cmd/`, `internal/`, build configuration (`go.mod`, `go.sum`, `Makefile`, `.golangci.yml`), and CI configuration.

In practice: anything an end user *runs* is AGPL.

## CC BY-SA 4.0 (LICENSE-CONTENT file)

Applies to documentation in `docs/`, the README, this file, AGENTS.md, CONTRIBUTING.md, and the format specification.

The Code of Conduct (`CODE_OF_CONDUCT.md`) is itself separately licensed under CC BY 4.0 per the Contributor Covenant's own terms.

In practice: anything an end user *reads* is CC BY-SA, except where a file's own header indicates otherwise.

## User-generated content

Curriculum manifests generated by the forge live on the user's local machine in `~/.local/share/lernen/manifests/`. These are not in the repository. The forge does not impose a license on the user's manifests; the user chooses how to license their own output if they share it.

## SPDX headers

Each source file in this repository should carry an SPDX license identifier in its header:

```go
// SPDX-License-Identifier: AGPL-3.0-or-later
```

```markdown
<!-- SPDX-License-Identifier: CC-BY-SA-4.0 -->
```

If you contribute a file, include the appropriate header.

## Why both?

Code under AGPL prevents the project from being forked, modified, and offered as a closed-source service. Documentation under CC BY-SA allows broad reuse of the project's ideas while preserving attribution and share-alike obligations. The combination is field-tested by Mastodon, Nextcloud, and Ghost.
